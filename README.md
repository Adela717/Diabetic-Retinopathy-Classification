# Diabetic Retinopathy Classification

A PyTorch CNN project for classifying retinal fundus images into five diabetic retinopathy classes.

## Dataset

[IS-2026 Set A v2 on Kaggle](https://www.kaggle.com/datasets/vladdraghici/is-2026-set-a-v2)

## Method

Uses group-stratified train, validation, and test splits, Ben Graham preprocessing, training-only image augmentation, and weighted sampling to address class imbalance.

## Run

Open the notebook in Kaggle, attach the dataset using **Add Input**, then run the cells from top to bottom.
